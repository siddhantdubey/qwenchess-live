# qwenchess-live

Live data for https://siddubey.com/qwenchess: Qwen3.5-4B (White) vs a chess engine running on the RISC-V CPU compiled into its own weights ([Qwenputer](https://divagr.com/blog/qwenputer)).

`live.json` is updated about once a minute during a game. It holds only the moves, Qwen's reasoning text, boards, instruction counts and timings.
